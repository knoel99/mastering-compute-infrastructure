# Calculs des exercices du module 6

`calc.py` recalcule, en bibliothèque standard, chaque chiffre cité dans les corrigés (cohérence du tableau 5 de Llama 3, mise à l'échelle du MTTF et projection par le taux de pannes de Kokolis et al., durée d'une mise à jour progressive, débit de bus, dimensionnement d'un volant de nœuds de rechange, compatibilité pilote/CUDA, placement d'instances MIG d'après la table de placement d'un A100 40 Go du guide MIG). Les entrées viennent de l'énoncé ou d'une source citée sur la page ; rien n'est mesuré ici.
