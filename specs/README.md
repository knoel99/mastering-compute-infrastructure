# specs/ — contrats

Chaque **nouveau module**, **projet** ou **jeu de données** a un contrat ici avant (ou dans la même livraison que) son contenu. Voir `AGENTS.md`.

| ID | Titre | Statut |
|---|---|---|
| `site-architecture` | Arborescence, rendu Pandoc, mise en ligne GitHub Pages | implémenté |
| `module-contract` | Contrat d'un module de cours (langue, en-tête, squelette, labs, exercices, sources) | implémenté |
| `project-contract` | Contrat d'un projet de portfolio | implémenté |
| `research-contract` | Taxonomie, formats et règles d'honnêteté des données de recherche (masters, offres, ressources) | implémenté |
| `_template-module.md` | Modèle de module | modèle |
| `curriculum-design` | Conception du parcours à partir de l'écart, de l'enquête sur les masters et des offres | en cours |
